# Movie Finder

A simple web application that fetches and displays popular movies using The Movie Database (TMDB) API. Users can also search for movies based on their queries.

## Features
- Displays popular movies with posters and descriptions.
- Allows users to search for movies by title.
- Responsive design for better user experience.
- Uses IMDB API to fetch movie data.

## Technologies Used
- HTML
- CSS 
- JavaScript 
- IMDB API
